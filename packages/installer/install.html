AI chat assistant for Word, Excel & PowerPoint — one-click install

🍎 macOS

Open Terminal (Cmd+Space → type "Terminal"), paste this command, press Enter:

curl -fsSL https://openword-longpt.pages.dev/installer/install-mac.command | bash

This downloads and runs the installer directly — no file saved, no Gatekeeper issues.

  1. Open Terminal (Cmd+Space → type "Terminal")
  2. Paste the command above and press Enter
  3. Quit and reopen Word, Excel, PowerPoint
  4. Open Home tab → Add-ins → your add-in appears
Prefer downloading the file? (may require extra steps)

If you download install-mac.command via browser, macOS may block it with "cannot be executed" error. Fix by running in Terminal:
xattr -d com.apple.quarantine ~/Downloads/install-mac.command
then double-click the file.

🪟 Windows

Download Installer Uninstaller
  1. Download install-windows.bat
  2. Double-click it
  3. Close and reopen Word, Excel, PowerPoint
  4. Open Home tab → Add-ins → your add-in appears

⚙️ Configure your AI provider

After installing, open the add-in's Settings panel and configure:

Provideropencode-go (or anthropic, openai, ...)
API Keyyour API key
Modelglm-5.2, deepseek-v4-flash, ...
CORS ProxyON
Proxy URLhttps://office-agents-cors-proxy.longpt-hrt.workers.dev

The CORS proxy is required for opencode-go and Anthropic — their APIs don't send CORS headers, so the Office webview blocks direct requests without it.
